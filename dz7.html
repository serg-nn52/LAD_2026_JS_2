Замечания по задачам

№1.1 — ответ только для строгого режима
В строгом режиме внутри функции действительно будет null. В обычном браузерном скрипте функция заменяет его глобальным объектом, и alert(this) покажет [object Window].

№1.3 — частично засчитано
Верно, что sayHi.test остаётся равным 5. bind() создаёт новую функцию, и свойство test у неё отсутствует. Поэтому alert(bound.test) выводит undefined.

№4.1 — нет объекта города
Создай city1 со свойствами name и population и методами, которые читают их через this.

№4.2 — нет вызовов в контексте второго города
Создай city2, вызови геттеры city1 в его контексте через call() или apply(), затем привяжи setProp() к city2 и вызови привязанный метод для изменения свойств.

Мелочи без снижения оценки
В №3.1 имя current яснее показывает, что переменная хранит текущее значение счётчика. Автоматический запуск через setInterval() был заданием со звёздочкой.
