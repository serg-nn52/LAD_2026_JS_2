Замечания по задачам

№1 — метод печатает строку
show() печатает строку и возвращает undefined. Верни строку через return, чтобы её можно было вывести или использовать в другом коде. Строки 6–8

№3 — регистр имени метода
Метод назван GetFullName(). Вызов worker.getFullName() из задания приводит к TypeError. Переименуй метод в getFullName(). Строки 73–78

№6* — формат даты
isDate() отклоняет 29.10.2026 из условия и принимает 2026-10-29. Проверь формат ДД.ММ.ГГГГ. Строки 109–126

№7 — частично засчитано
Boss наследуется от Worker, вызывает super() и сохраняет число подчинённых в workers. Зарплата пока считается по базовой формуле: при ставке 5000, 20 днях и 10 подчинённых получается 100 000 вместо 1 000 000. Добавь getSalary(), который возвращает super.getSalary() * this.workers. Строки 138–146

№8 — порядок аргументов конструктора
Конструктор принимает (year, name, surname). При вызове из условия new Student("Anna", "Smirnova", 2024) метод getCourse() возвращает NaN, а имя получается «Smirnova 2024». Используй порядок (name, surname, year). Базовая формула курса верна при текущем порядке аргументов. Для пункта со звёздочкой учитывай месяц, чтобы курс повышался 1 сентября. Строки 161–178

Мелочи без снижения оценки
В №1 Postcard.prototype.show.call(postcard1) корректно передаёт контекст. Для примера достаточно обычного вызова postcard1.show(). В №3 имя переменной workernew можно упростить до worker. В №6* проверки email и телефона допускают более широкий ввод, чем в условии.

Замечания по задачам

№2 — нет объяснения результата
Результаты true и undefined указаны верно. Добавь объяснение: метод найден в прототипе, но вызов rabbit.eat() привязывает this к rabbit. Поэтому full записывается в rabbit, а у animal свойство отсутствует.

№4 — сеттер принимает бесконечность
При присваивании worker.rate = Infinity ставка меняется и зарплата становится бесконечной. Добавь проверку Number.isFinite(value) вместе с условием value > 0.

№7 — повторяется расчёт зарплаты
Зарплата считается правильно, но Boss повторяет формулу Worker. Используй super.getSalary() * this.workers, чтобы изменения базового расчёта автоматически применялись и к начальнику.

Мелочи без снижения оценки
В №5 переменная result хранит массив слов с заглавными буквами. Имя capitalizedWords точнее описывает это значение. В №8 достаточно создать один объект Date и взять из него год и месяц. В №6* можно добавить поддержку поддоменов в isEmail(), переиспользовав isDomain().

Сильные стороны

Замечания по задачам

№4 — сеттер принимает NaN и Infinity
Сеттер rate сохраняет NaN и Infinity. Из-за этого зарплата может стать NaN или Infinity. Проверь Number.isFinite(value) и положительность перед записью. Строки 72–82

№5 — повторяется логика ucFirst()
ucWords() корректно обрабатывает пустую строку и повторные пробелы, но повторяет преобразование из ucFirst(). Вызови this.ucFirst(word) внутри map(), чтобы правила преобразования были в одном методе. Строки 124–138

№8 — нет классов User и Student
Файл заканчивается примером для Boss. Добавь классы User и Student extends User с методом getCourse(). Строки 187–201

Мелочи без снижения оценки
В №4 проверка typeof value !== "number" в сеттере days избыточна: Number.isInteger(value) уже отклоняет значения других типов. Проверка целого неотрицательного числа работает. В №6* можно переиспользовать isDomain() в isEmail(), чтобы проверять доменную часть по тем же правилам.
