Хан Владислав Станиславович · ДЗ №3 · indexhw3_vlad.js

Сильные стороны: условия в №1.2–1.8 и №3 записаны верно, в №1.8 — строгое ===, как и нужно. В №3.4 поставил скобки вокруг каждой пары && — так условие читается сразу. В №4.1 и №5 добавил default/else на некорректный ввод — хорошая привычка. №6.3 через i % 2 === 0 — верно.

№1.1 — код не запустится: между } и else стоит ;. Точка с запятой закрывает инструкцию if, и else оказывается «висячим» → SyntaxError: Unexpected token 'else' (проверил запуском). Убери ; после }:

if (a === 0) {
  console.log('Верно');
} else {
  console.log('Неверно');
}

№2.1–2.2 — нужны обе формы: по заданию для каждой задачи два варианта: короткий (if (test) / if (!test)) и длинный (if (test === true) / if (test !== true)). У тебя только длинный, и через нестрогие ==/!=. Плюс проверял на test = 0, а по заданию — true и false. С 0 видно ещё и подвох: 0 == true → false, но это уже приведение типов, а не работа с логической переменной.

№4.1 — результат в result: по заданию пору года нужно записать в переменную result, а у тебя сразу console.log. Объяви let result;, в каждом case присваивай result = 'зима' и т.д., а вывод сделай один раз после switch.

№5.2 — имя переменной: mount — это «гора/крепление», а месяц — month. Логика при этом верная: декабрь правильно отнесён к зиме.

№5.3 — засчитано, ответ на твой вопрос: startsWith('a') работает правильно. На занятии подразумевался доступ по индексу — str[0] === 'a' (или str.charAt(0)). Оба способа верные, индекс пригодится дальше — в циклах по строкам.

№6.1–6.4 — нет while: по условию каждую задачу нужно решить дважды — через while и через for. У тебя только for. Пример для №6.1:

let i = 1;
while (i <= 100) {
  console.log(i);
  i++; // без инкремента — бесконечный цикл
}

№7.1 — не сделано: задачи в файле нет. Ожидается: n = 1000, делить на 2, пока n >= 50, считать проходы в num → получится 31.25 и 5.

Мелочь: в №1.6 != работает, но эталон — строгое !==. Привыкай к строгим сравнениям по умолчанию.

№3.2 — не те действия: условие верное, но нужно не вывести 'Верно'/'Неверно', а изменить a: a += 7 или a /= 10, и вывести новое значение (ожидается 5 → 0.5, 0 → 7, -3 → -0.3, 2 → 9).

№4.1 — case (num = 1) — это присваивание: в case пишут значение, с которым сравнивают: case 1:. Твоя запись (num = 1) перезаписывает num и только поэтому «случайно» совпадает. Если передать, например, num = 7, все case по очереди перезапишут num, и после switch в нём окажется 4 — данные испорчены.

switch (num) {
  case 1:
    result = 'зима';
    break;
  case 2:
    result = 'весна';
    break;
  // …
}

№6.1–6.3 — нет while и счётчик без let: каждую задачу нужно решить дважды — while и for; у тебя только for. И в for (a = 1; …) переменная a не объявлена — получается неявная глобальная переменная (в строгом режиме — ReferenceError). Пиши for (let i = 1; …).

№6.4 — граница цикла: i < 100 не включает 100 → сумма 4950 вместо 5050. Это классическая ошибка «не включаю последнее». Нужно i <= 100. Ты даже вывел 4950 — сверяй результат с ожиданием (сумма 1..100 = 5050). И здесь тоже нет варианта с while.

Мелочи: в №7.1 по заданию счётчик нужно записать в переменную num, у тебя count — имя хорошее, но условие задачи стоит соблюдать. В №5.1 опечатка в строке: «Третья декад».
