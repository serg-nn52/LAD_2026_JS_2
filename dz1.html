№2 — имена переменных: типы на месте, let/const использованы, но посмотри на имена. bool — это имя типа, а не роль: по нему непонятно, что переменная означает (лучше isStudent, hasAccess). А bag совсем не говорит, что это «пустая» переменная под null — лучше favoriteCar = null. Хорошие примеры у тебя — nameWeapon, userName.

№5 — поймана не та ошибка: здесь нужно было именно изменить переменную const — то есть переприсвоить значение:

nameWeapon = 'M4A1';   // ← без const → TypeError: Assignment to constant variable

У тебя же получилось повторное объявление:

const nameWeapon = 'M4A1'   // ← с const → SyntaxError: Identifier has already been declared

Это разные вещи: переприсвоение запрещает const, а повторное объявление не даёт сам язык. Поправь, пожалуйста, именно на переприсвоение — на этом строится вся разница заданий 5–8. С let то же присваивание сработало бы.

№7 — опечатка:

enemy.name = 'Oleg'
console.log(user.name)   // ← user не существует → ReferenceError; должно быть enemy.name

Правь, пожалуйста: user у тебя нет, поэтому код бы упал. Комментарий «Получилось» здесь фактически неверен.

№2 — имена переменных: типы и ключевые слова let/const на месте, но посмотри на имена: number, text, value, nothing описывают тип, а не смысл значения. Пусть имя говорит о том, что это: userAge, userName, balance = null и т.п.

№4: обе формы typeof ты привёл, но задание просило словами объяснить, почему скобки не превращают typeof в функцию. А это — оператор: скобки лишь группируют операнд. Добавь, пожалуйста, одно предложение с этим объяснением.

№5 — не та операция: «изменить переменную const» означает переприсвоить её:

change = 7;              // ← без const/let → TypeError: Assignment to constant variable

У тебя же получилось повторное объявление const change = 6; let change = 7; → SyntaxError. Это разные вещи: переприсвоение запрещает const, повторное объявление — сам язык. Переделай, пожалуйста, именно на переприсвоение.

Стиль — комментарии: по технике оформления: в файле много строк с ///. В JS нет «тройного комментария» — это просто // плюс лишняя косая как текст (например // /let…). Похоже, комментировалось вручную и один слой // наложился на другой. В редакторе комментирование делают одной клавишей (Ctrl+/ / Cmd+/) — она ставит ровно один // и так же его снимает.
