Подробные комментарии

Кальянов Никита · ДЗ №9 · script.js

Сильные стороны
Один обработчик на списке различает клик по тексту и по кнопке «Удалить». Первый переключает зачёркивание, второй удаляет только выбранную задачу. Клик по пустому месту сохраняет список.

Мелочи без снижения оценки
Для запуска из папки проекта укажи в HTML относительный путь ./script.js. Текущий /script.js требует размещения проекта в корне сайта.

Новокшонова Наталья Сергеевна · ДЗ №9 · index.js

Сильные стороны
Обработчик списка находит задачу через closest("li"). Первый клик зачёркивает текст, второй снимает зачёркивание. Клик по пустому месту ничего не меняет. Клавиша Enter вызывает тот же обработчик добавления, что и кнопка.

Хан Владислав Станиславович · ДЗ №9 · script.js

Сильные стороны
Интерфейс создаётся через JavaScript. Кнопка добавляет задачи по порядку и очищает поле. Проверка через trim() отсекает пустой ввод, а textContent выводит угловые скобки как текст.

Замечания по задачам

№3 — действие по клику на задачу
Клик по добавленной задаче ничего не меняет. Добавь один обработчик click на ul. Найди строку через event.target.closest("li") и, если она найдена, вызови li.remove(). Проверь удаление второй задачи и клик по пустому списку.

Мелочи без снижения оценки
Для запуска из папки ДЗ укажи в HTML ./script.js вместо /js/hw9/script.js.
